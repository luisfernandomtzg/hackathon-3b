Validat3B · Motor de Validación PriceCheck

Ficha Técnica · Reto 2

1. Qué es

Motor automático por lotes que valida capturas de precios en campo (fachada, producto y etiqueta) para emitir decisiones auditables (aprobada, rechazada o revision_manual) a mínimo costo operativo.

2. Tubería de procesamiento

1. Señales locales 0 tokens: nitidez, código de barras (zxing-cpp) y huella de fachada.
2. Lectura VLM claude-haiku-5-5 (1 llamada/captura, imágenes reducidas y caché).
3. Reglas puras Cruce determinista de marca, descripción, contenido y precio.
4. JSON oficial Salida validada con pydantic, reason_code y confianza.

3. Cómo decide

  • Aprobar: solo cuando marca, descripción, contenido y precio son legibles y coinciden con certeza.
  • Rechazar: cuando la evidencia falla con claridad (foto borrosa, lejana o incompleta) con su motivo exacto.
  • Revisión manual: únicamente en la zona de duda para evitar falsos positivos (10 pts vs. 1 pt).

4. Tecnologías

  • Lenguaje y validación: Python + pydantic
  • IA Multimodal: Endpoint asignado de Azure AI Foundry (claude-haiku-5-5)
  • Procesamiento local: zxing-cpp (códigos de barras) y Pillow (imagen y compresión)

5. Resultados medidos

[[COSTO]]Costo operativo
[[PRECISION]]Precisión aprobadas
[[TOKENS]]Tokens / captura
[[SEGUNDOS]]Segundos totales

6. Cómo correrlo

python -m ml.validat3b.correr --datos datos/privado --salida salidas/resultados.json
python -m ml.validat3b.evaluar --datos datos/privado --resultados salidas/resultados.json
python -m ml.validat3b.visor --datos datos/privado --resultados salidas/resultados.json --salida salidas/visor.html
